# The Human Heart
A simple, light-themed learning website about the heart.

## How to run
1. Open this folder in VS Code.
2. Right-click `index.html` and choose "Open with Live Server" (or just double-click the file to open it in your browser).

## Files
- `index.html`: the page content
- `css/style.css`: colours and layout (change colours at the top, in `:root`)
- `js/script.js`: the interactive parts, in numbered sections with comments

Everything is original and uses no libraries. This site is for learning only and is not medical advice.
